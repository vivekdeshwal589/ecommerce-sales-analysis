# E-Commerce Sales Analysis

## Project Overview
An end-to-end E-Commerce Sales Analysis project using Excel,
MySQL, Python and Power BI.

## Dataset
The dataset contains 1,000 e-commerce orders with information
about products, categories, sales, profit, cities and states.

## Tools & Technologies
- Excel
- MySQL
- SQL
- Python
- Power BI
- Data Visualization

## Analysis Performed
- Total Sales
- Total Profit
- Total Orders
- Sales by Category
- Sales by State
- Monthly Sales Trend
- Top 10 Products by Sales
- Profit by Category
- Top 10 Products by Profit

## Power BI Dashboard
Created an interactive dashboard to analyze sales,
profit and order performance.

## Key Skills
Data Cleaning | SQL | MySQL | Excel | Python |
Power BI | Data Visualization | Dashboard Development
